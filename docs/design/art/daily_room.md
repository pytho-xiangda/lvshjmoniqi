# 日常房间 · 午后办公与生活

> 本文记录 v01/v02 透视草案。当前游戏接入版本已经改为固定正侧视横版房间，见 `daily_room_side_v03.md`。

当前背景：`assets/art/daily/daily_room_warm_v02.png`，1672×941，RGB PNG，约 16:9。以实际分辨率导入；布局缩放保持纵横比，不裁切电脑桌和门口。v01 是旧电脑的历史草案，当前使用 v02。

## 美术方向

参考 `assets/art/main_menu_concept.png` 与 `assets/art/characters/protagonists_concept.png`，延续暖色水彩、棕色铅笔线、纸张颗粒和自然成人比例。结合用户提出的宫崎骏动画式生活空间氛围，强调旧木家具、植物、日光与生活细节，保持当代中国年轻律师的居住背景。

房间为主角兼具办公、阅读与休息用途的小居室。木地板、奶油色墙面、胡桃木家具构成主体；鼠尾草绿和窗外天空蓝平衡暖色。电脑使用当代窄边薄屏显示器、键盘、鼠标和桌下主机，旧木家具保留生活质感。

采用固定、稍俯视的三分之四机位。电脑桌与门口形成两个清晰的操作目标，中间保留连续走动区域。书柜、阅读椅、茶杯、卷宗、帆布包和植物沿房间边缘布置，装饰不占据主要动线。

场景背景不烘焙角色、功能按钮或选项文字，便于引擎叠加人物、热区和原生 UI。男性主角仅作为当前视觉参考，房间同样适用于另一主角外观。

本张构图中电脑桌位于左下，椅子前留出站位；右后方木门为外出入口。中间地面连通两者。书柜与便笺板在后墙，阅读椅在右侧。

## 日常界面交互

1. 点击可达地面：主角走到目标位置。家具区域设置碰撞，寻路不穿过桌子、椅子或书柜。
2. 点击电脑桌：主角先走到椅子前的交互点，朝向桌面，播放坐下动作；随后切换至电脑界面并弹出行动选项。
3. 电脑内以“工作／学习／社交”等 GDD 已有行动类型组织功能。具体工作和目的由当前章节、案件、角色状态提供；本房间设计不新增奖励数值。返回后恢复坐在桌前的状态，离开桌子时播放起身动作。
4. 点击房门：主角先走到门前，再展示当前章节已解锁的目的地。确认后切换至目标场景；取消则留在门前，不改变场景。
5. 移动中重复点击允许更新目标；坐下、起身或场景切换期间防止重复触发。电脑面板和目的地列表打开时，房间地面点击不穿透。

操作提示由引擎绘制：电脑桌显示“办公”，门口显示“外出”；鼠标悬停或接近后出现，避免长期覆盖画面。字体、奶油纸色面板与森林绿交互强调遵循 `art_direction.md`。

## 装配建议与交付边界

已制作背景、人物行走素材和浏览器交互预览；尚未完成坐下／起身、正式待机、任意地面寻路或真实任务／场景切换。停止时暂用行走帧定格，后续需要独立站立循环。当前仓库没有 `project.godot`，因此未执行 Godot 导入与运行验证。

推荐节点关系：房间背景、家具碰撞与导航区、可走动主角、桌面交互点、房门交互点、电脑界面、目的地面板。以人物脚底为位置锚点，根据纵深微调角色比例。

在制作正式坐下动作前，需要把椅背／桌沿等遮挡部分拆成前景图层，并补齐主角相同机位的站立、转身与坐姿动画，避免角色直接穿过烘焙在背景中的椅子。当前路线停在椅子右侧。窗帘、窗外树叶和光斑可在后续拆层后加入轻微循环；阅读选项时保持 UI 稳定。

图片由内置 imagegen 根据项目参考图生成；初稿提示词见 `daily_room_prompt.md`，电脑修订与人物提示词见 `daily_room_motion_prompts.md`。

验收：检查了门口、行走途中与桌前三处合成画面，人物透明边缘、脚底与路线无明显穿家具问题；背景保留独立空房间版本。浏览器检查覆盖办公与外出面板、Esc 关闭、窄屏布局和页面脚本错误。逐帧姿态与定格仍属于动作试作，正式投产前需要进一步润色。
