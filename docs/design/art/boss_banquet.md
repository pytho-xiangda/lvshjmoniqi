# 宴席客：勾兑型庭审 Boss

2026-09-08。按用户最新方向，对手不限于律师，可以是当事人、检察官或其他案件角色。人物的手段、性格和资源可以外化为超出真实人体比例的纸境构造；异常外形在此表现庭审压力与战斗能力。

## 造型与场上层级

本例为虚构的对方当事人，工作代号「宴席客」，不是对方代理律师。身体呈酒瓮般的巨大梨形，头部与下肢相对缩小；眯眼、油滑笑容、举杯和包裹腹部的紧绷宴席马甲，共同表现他擅长经营关系、把庭审拖入人情场的特点。

腹部由浸油的厚纸层构成，接缝分泌黑金油脂与暗红酒液。流体是油墨与漆纸质感，不画写实伤口。油脂负责缓慢扩散的地盘压力，酒液负责发动时朝审判席推进的方向反馈。主色仍为冷黑、旧象牙白和暗酒红，避免宴会般温暖轻松的氛围。

法官保留第三方身份：远、小、暗；脸部大面积阴影，眼部不可辨，双手撑在桌面，动效以桌面为支点保持手掌稳定。玩家与对方角色承担主要视觉对抗，不给法官 Boss 式亮面、光环或巨大头像。

## 周期招式草案：觥筹交错

以下数值用于动态预览，尚未进行正式平衡。

| 时点 | 外观预兆 | 结算 |
| --- | --- | --- |
| 蓄势 0/3 | 腹部缓慢起伏，纸缝渗油 | 第 1 回合，对方普通狡辩 |
| 蓄势 1/3 | 油膜扩大，接缝更加潮湿 | 第 2 回合，对方普通狡辩 |
| 蓄势 2/3 | 举杯预警，酒液路径显现，标注「本回合结束时发动」 | 第 3 回合给玩家最后一次响应机会 |
| 发动 | 暗红酒液沿地面伸向审判席，心证栏沾染酒色 | 对方行动额外施加 8 点心证压力，然后蓄势归零 |

- 每次结束回合推进一格；第 3、6、9……次对方行动触发。正式阶段切换保留蓄势，不能靠阶段刷新绕过预告；当前页面仅演示法庭调查阶段。
- 普通狡辩压力为 3。发动时总压力为 3＋8，已有减伤抵扣总压力，心证最低为 0。酒色标记只是本次影响提示，不另加持续扣点。
- **对手弱点**：发动所在回合若已打出程序卡，则打断额外 8 点压力并清空蓄势；普通狡辩仍会结算。提前回合使用程序卡不会把打断资格保留到发动回合。
- 打断属于该 Boss 对程序行动的特殊弱点；现有卡牌的数值、文字、插画比例和消耗方式保留。
- 不让法官化身攻击单位，不强制夺走玩家整回合，不隐藏发动倒计时。后续可用实际证据揭露关系链，但本次不增加未实现的卡牌效果。

## 已实现的预览与正式资源边界

`paper_battle_preview.html` 已演示蓄势计数、危险预告、酒液路径、心证结算和程序打断。腹部膨胀与呼吸暂用整图缩放模拟；尚未拆出腹部、滴液、袖口和酒杯骨骼。油膜扩大、纸层湿润等逐阶段材质变化仍属于正式动效制作目标，不能当成当前页面已有的逐帧动画。
