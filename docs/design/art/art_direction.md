# 律师模拟器 · 统一美术与 UI 规范

> 2026-09-06 · v0.1。用户已确认主界面风格为游戏主要美术方向。
> 权威规则见 `docs/GDD.md`；本文件定义视觉实现，不修改案件规则和数值平衡。

## 1. 视觉基准

日常场景首要参考：`assets/art/main_menu_concept.png`。关键词是“午后的律所、纸张的温度、普通人的职业人生”：原创暖色手绘水彩、细棕色铅笔线、低饱和颜料、暖日光、真实生活物件。庭审战斗已单独选定超现实纸境：`assets/art/battle/courtroom_surreal_paper.png` 与 `assets/art/cards/card_surreal_paper_states.png`，人物与动效遵循 `paper_battle_motion.md`，允许在对抗场景中明显转变材质与情绪。

场景可见水彩颗粒，文字后面的面板应接近纯色；避免所有内容覆盖强纹理。避免赛博霓虹、厚重金属奇幻框、Q 版大头、塑料高光和过度美颜。服饰与空间按当代中国职场设定，具体执业与法庭服装在正式制作时单独核对。

颜色均为执行目标，生成图允许自然颜料差异。正文与底色需在实现时检查对比度（普通文字目标至少 4.5:1），不能用浅金色承载小号正文。禁用态除降低饱和度，还要有“暂无存档”“阶段不符”等明确原因。成功/风险同时用文字和图形表达。

1920×1080 设计基准：外边距 64，8 px 间距网格；主要按钮高 56–64，交互目标不小于 48×48；正文 26–30，对话 30–34，辅助字 22–24，页面标题 40–48。正式标题用思源宋体类衬线，功能正文用思源黑体类无衬线；字体在接入前确认授权并随资源登记，目前未打包字体。所有正文由引擎绘制，不烘焙进背景。面板小圆角 4–8 px，细线 1–2 px，轻微纸边阴影；不做厚重仿旧破损。

### 立绘制作交付规格

本轮是有纸底的设定合页，不是透明可直接装配立绘，也不是动画。正式交付每角色每姿态单独透明 PNG，建议 1536×2560、RGBA/sRGB，脸部/手指边缘无白边，至少保留 96 px 安全边距；同角色所有差分画布、身高与脚底锚点一致。身体、表情可拆层时保留源文件。例：`npc_mentor_stand_neutral_v01.png`。禁止用整张设定图裁切后直接宣称是合格透明素材。

## 4. UI 页面设计

### 办公室：每周行动中枢

- 顶部：章节/第几周，专业、口碑、人际、财富、精力；不出现良知。
- 精力与本周剩余行动点分开表达，行动点预算来源于精力；示意数字不定义换算公式。
- 风声只显示“平静 / 有闲话 / 被盯上 / 在逃边缘”，不显示精确违法值或进度条。
- 中央保留律所窗景和人物，左侧卷宗纸条展示主线目标，右侧纸质行动栏提供工作/学习/社交/休息及日常任务。
- 行动卡明确任务、耗费、可预见收益；执行前展示摘要，需要确认时确认框优先聚焦取消。关闭或取消不扣点。
- 底部导航：办公室、案件、卡组、人物、日志；右侧“结束本周”。尚有行动点时结束本周需确认。
- 图片中的预算、财富、卡牌奖励均为视觉占位，不可直接移入正式配置。

### 对话与选择

- 上方保留场景与双人半身/立绘空间；发言者正常明度，另一方轻微减暗，不改变角色肤色。
- 底部约 25% 高度为高不透明度奶油白阅读面板，独立姓名签、正文、继续提示。
- 选择项竖排在对话框上方的安静区域，一行最多约 24 汉字，过长换行；明确焦点和数字快捷键。
- 历史、自动、跳过、设置保持次级层级。跳过只用于已读文本且在选择前停止。
- 隐藏良知和风声精确变化；只有剧情中玩家合理可知的成本展示，不以红绿按钮替玩家做道德判断。
- 生成对白是布局示例，不新增正式剧情事件。

### 庭审与卡牌

- 顶部按 GDD 五阶段横排：开庭准备 → 法庭调查 → 法庭辩论 → 最后陈述 → 调解或宣判。民事显示调解/宣判，刑事末段显示宣判。
- 中央上方独立心证条 0–100，注明当前数值；它是法官判断/可消费战术资源，不是对手血量。
- 场景中法官居中，双方分别位于两侧；右侧轻量显示对方下一步行动提示，不能将法官画成敌人。
- 底部手牌依次突出卡名、阶段标签、卡牌类别、效果与消耗类型；本轮不设未经 GDD 定义的统一法力资源。
- 可用牌：森林绿描边；悬停/焦点：上移约 16 px 并在旁边放大；不可用牌：清晰锁标与“阶段不符”，正文仍可阅读。
- “结束回合”固定右下；出牌前目标高亮，非法目标不可确认，结算期间防重复提交。
- 案例中的卡名、效果、心证数值均为版式示意。不能将示意“+8”等值视为平衡结论。
- 调查阶段展示证据/发问/质证卡；法条/辩论卡阶段不符。程序卡全阶段可用，但折扣效果由配置解释。
- 八类卡通过图标和中文类型共同识别：程序（卷页）、发问（问号）、证据（夹页）、质证（放大镜）、法条（书）、辩论（对话）、陈述（钢笔）、调解（握手）。消耗类型另设文字标签，不与类别混用。

## 5. 交互状态与适配

组件至少具备默认、悬停、键盘焦点、按下、禁用五态。键盘焦点用双线细框+箭头，不能只改变颜色。按钮悬停 120 ms，面板进入 180–220 ms；支持减少动态，关闭飘叶/光斑/视差并降低过场动效。声音是后续资源，不代表本轮已制作。

Godot 接入建议：Control + Container 布局、Theme 统一 token、NinePatchRect/StyleBoxTexture 纸质边框、RichTextLabel 正文。以 1920×1080 为基准适配 16:9；超宽扩展场景但锁定阅读栏宽，4:3/16:10 优先重排侧栏和卡牌区，不能简单裁切关键按钮。文字放大到 125% 时，正文面板与选项需随内容增高。正式接入后检查 1280×720、1920×1080、2560×1440 及键盘全流程。
