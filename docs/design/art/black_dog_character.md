# 黑狗角色设定

> 2026-09-14 · v0.1。依据用户提供的同一只幼犬照片建立幼年与成年视觉方案。

## 身份锚点

- 幼年：蓬松略乱的黑毛、宽圆软垂耳、带冷蓝反光的大眼睛、小白下巴与胸斑、短腿小爪、上卷毛尾。
- 成年：保留相同耳型、眼色、白色标记与卷尾；口鼻、四肢和躯干自然拉长，胸腔加深，体型为健康的中型中华田园犬，不转化为德牧等明确犬种。
- 两个年龄阶段都保持亲切、好奇、警觉的气质，不穿衣、不加项圈。

## 固定色板

| 用途 | 色值 |
|---|---|
| 黑毛基色 | `#1B1716` |
| 暖色毛发高光 | `#3A2A24` |
| 眼睛棕色 | `#5A3D2A` |
| 眼睛冷蓝反光 | `#7FB6D8` |
| 下巴与胸口白毛 | `#E9DDC9` |
| 鼻头与最深轮廓 | `#0E0D0D` |
