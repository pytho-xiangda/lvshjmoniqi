# 日常房间电影光影横版概念图 v02

## 定位

- 用途：律师模拟器日常界面的超宽横版房间背景。
- 画幅：1916 × 821，约 21:9。
- 生成方式：文生图。
- 风格原则：使用电影动画常见的通透天空、雨后反光、空气透视和手绘环境质感，保持原创构图与原创设计。

## 游戏构图

- 左侧设置大窗与阳台，作为天空、云层、山城和植物的动态视差区。
- 中下部留出贯穿画面的平整木地板，供角色横向行走和播放完整步态。
- 右侧设置现代薄屏电脑、工作椅和法律文件，构成办公交互区。
- 最右侧房门轮廓清晰，可直接作为场景切换热点。
- 前景植物、可行走中景、家具墙面、窗外城市与天空可拆成五层视差素材。

## 建议裁切层

1. 前景：画面底部两侧虚化植物。
2. 角色层：木地板中下部的连续空区。
3. 家具层：书柜、电脑桌、椅子和房门。
4. 窗外层：阳台、建筑、湖面和山体。
5. 天空层：蓝天、云层与远景光照。
