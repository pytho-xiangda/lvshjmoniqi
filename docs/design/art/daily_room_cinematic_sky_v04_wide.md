# 日常房间电影光影横版概念图 v04

## 定位

- 用途：律师模拟器日常界面的超宽横版房间背景推荐稿。
- 画幅：1916 × 821，约 21:9。
- 生成方式：以 v03 为参考图进行布局修订。

## 核心调整

- 电脑桌移动到画面中间偏左，与书柜形成完整办公区。
- 右半部作为主要角色表演区，房门与电脑之间具有足够的行走距离。
- 门口、行走段和椅子落座点形成清楚的水平动线，适合速度驱动步频与相机跟拍。
- 椅子四周保留转身、拉椅和落座的动作空间。
- 左侧窗景仍可拆分为天空、山城、阳台和窗帘视差层。

## 动画接入建议

- 入场点设在右侧门垫左边。
- 在右侧空墙区域安排短暂停顿与起步预备动作。
- 巡航行走横跨右半区，到电脑桌右侧开始减速。
- 落座前在椅子右侧停顿约 0.3–0.4 秒，再衔接转身和拉椅动作。
- 相机可在行走时轻微滞后，落座后向电脑区域缓慢推近。
