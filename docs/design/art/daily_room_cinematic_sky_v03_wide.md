# 日常房间电影光影横版概念图 v03

## 定位

- 用途：律师模拟器日常界面的超宽横版房间背景推荐稿。
- 画幅：1915 × 821，约 21:9。
- 生成方式：以 v02 为参考图进行局部构图修订。
- 风格原则：使用电影动画常见的通透天空、雨后反光、空气透视和手绘环境质感，保持原创构图与原创设计。

## 相对 v02 的调整

- 将电脑桌整体左移至中部偏右，避免办公交互区紧贴房门。
- 在电脑桌和右侧房门之间留出约 1.5–2 米的玄关缓冲区。
- 保持门口到工作椅之间的地面连续无阻挡，便于安排进门、停顿、行走和落座动作。
- 工作椅后方保留活动空间，方便制作椅子后移、回弹与坐下动画。
- 重新平衡书柜、桌面和墙面留白，使办公区轮廓更清楚。

## 交互位置建议

- 房门热点：画面最右侧门扇与门垫区域。
- 电脑热点：显示器、键盘和工作椅组成的中右区域。
- 角色入场点：门口左侧空地。
- 落座对齐点：工作椅中心略偏右处。
