# 主角（玩家角色）

- id: pc_main
- 姓名: 待定（预留命名；性别可选）
- 职业: 律所新人 · 实习律师（尚未通过律师助理考核）
- 教育背景: 211 高校法学本科，已通过法律职业资格考试
- 履历: 曾在本地法院民庭实习
- 初始数值: 专业中、人际中、财富低、精力中、良知高、口碑低
- 立场: 中立偏正（由玩家选择塑造）

## 设定要点

- "未过律师助理考核 + 法院民庭实习过"是两条关键人脉触发点：实习时认识的书记员/法官会在后续认出来，带来信息或阻力。
- 起点低意味着开局资源匮乏，必须靠日常任务（带教、法援、学习）积累卡牌和数值，与核心循环一致。
- 性格由玩家行为决定，不预设；「良知」隐藏值对结局和法官心证有决定性影响。

## 与其他 NPC 的关系锚点

- 带教律师（徐正源）：直属导师，决定案件分配。
- 同期实习律师（赵一鸣）：战友兼暗自较劲。
- 原法官带教（周德明）：因法院实习经历被额外提点。
- 法官矩阵：民庭实习经历让部分法官对你有"熟脸"或"生涩"两种印象。
